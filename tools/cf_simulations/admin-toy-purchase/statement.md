# 行政大大的玩具收購

## Statement

行政大大最近在收購他的新玩具。

雖然他有錢到可以把所有東西全部收入囊中，但他不能這樣做，
不然會被大家發現他很富。

所以他最多只能收購總價值不超過 `x` 的玩具。

現在給你長度為 `n` 的收購列表，`bag_i` 表示第 `i` 個物品的價值。
請問「總價值小於等於 `x`」的子集合有幾種。

## Input

輸入共兩行：

第一行包含兩個整數 `n x`。

第二行包含 `n` 個整數 `bag_1 ... bag_n`。

## Output

輸出一個整數，表示可行子集合的數量。

## Constraints

- `1 <= n <= 30`
- `1 <= bag_i <= 10^5`
- `1 <= x <= 5 * 10^5`

## Sample

Input

```text
5 600
20 30 50 100 10
```

Output

```text
32
```

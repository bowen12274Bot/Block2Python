# Input Gate: Terminal Handshake

## Story

You arrive at the Input Gate. The terminal asks for a valid greeting format before it opens.

## Task

Read one line of text `name` (it may contain spaces), then print:

`Hello, <name>!`

## Input

- One line: `name`

## Output

- One line: `Hello, <name>!`

## Constraints

- `1 <= len(name) <= 64`
- `name` uses printable ASCII characters

## Example

### Input

```text
Ada Lovelace
```

### Output

```text
Hello, Ada Lovelace!
```

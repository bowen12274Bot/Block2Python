# Variable Base: Memory Ledger Boot

## Statement

Read one token `callsign` and one integer `charge`.

Print exactly:

- `callsign=<callsign>`
- `charge=<charge>`

## Input

- Line 1: `callsign` (letters only)
- Line 2: integer `charge`

## Output

Two lines in the exact format above.

## Constraints

- `1 <= len(callsign) <= 20`
- `-10^9 <= charge <= 10^9`

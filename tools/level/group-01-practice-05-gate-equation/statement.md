# Group 01 Practice 05: Gate Equation

## Task

Read three integers `a`, `b`, and `x`, then print:

`a * x + b`

## Input

- Line 1: integer `a`
- Line 2: integer `b`
- Line 3: integer `x`

## Output

- One integer: `a * x + b`

## Constraints

- `-10^9 <= a, b, x <= 10^9`

## Example

### Input

```text
3
2
7
```

### Output

```text
23
```

# Group 01 Practice 04: Rect Scan

## Task

Read two positive integers `w` and `h`, then output:

- `w * h` (area)
- `2 * (w + h)` (perimeter)

Print both values in one line separated by one space.

## Input

- Line 1: integer `w`
- Line 2: integer `h`

## Output

- One line with two integers: `<area> <perimeter>`

## Constraints

- `1 <= w, h <= 10^9`

## Example

### Input

```text
3
5
```

### Output

```text
15 16
```

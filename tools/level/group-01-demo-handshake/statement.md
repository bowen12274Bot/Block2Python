# Group 01 Demo: Signal Calibration

## Task

Read one line string `codename` (it may contain spaces), then print:

`Signal: <codename>`

## Input

- One line: `codename`

## Output

- One line: `Signal: <codename>`

## Constraints

- `1 <= len(codename) <= 64`
- `codename` contains printable ASCII characters only

## Example

### Input

```text
Main Hub
```

### Output

```text
Signal: Main Hub
```

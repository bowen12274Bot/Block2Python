# Group 01 Practice 02: Sum Two Integers

## Task

Read two integers `a` and `b` from standard input, then print `a + b`.

## Input

- Line 1: integer `a`
- Line 2: integer `b`

## Output

- One integer: `a + b`

## Constraints

- `-10^9 <= a, b <= 10^9`

## Example

### Input

```text
2
5
```

### Output

```text
7
```

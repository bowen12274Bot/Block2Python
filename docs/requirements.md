# 需求總覽

- 文件版本：3.0
- 更新日期：2026-03-22

本文件是需求閱讀入口，用來說明目前需求文件的閱讀順序與分工。

如果要理解這個專案的需求，建議依照下面順序閱讀：

1. `docs/requirements/product_context.md`
2. `docs/requirements/gameplay_requirements.md`
3. `docs/requirements/quality_and_open_questions.md`
4. `docs/requirements/core/story_presentation_requirements.md`

## 1. 閱讀順序

### 1.1 先看背景

- `docs/requirements/product_context.md`
  - 說明世界觀、需求範圍與玩家主流程。

這份文件的目的不是列功能，而是先建立需求判斷的上下文。

### 1.2 再看需求條目

- `docs/requirements/gameplay_requirements.md`
  - 列出正式功能需求。
- `docs/requirements/core/story_presentation_requirements.md`
  - 列出劇情演出的細部延伸需求。

### 1.3 最後看補充與未定案項目

- `docs/requirements/quality_and_open_questions.md`
  - 列出非功能需求與尚未定案、後續要補的資訊。

## 2. 文件分工

- `docs/requirements.md`
  - 總覽入口，只負責閱讀引導與文件定位。
- `docs/requirements/product_context.md`
  - 背景、範圍與流程的整合脈絡。
- `docs/requirements/gameplay_requirements.md`
  - 核心功能需求本體。
- `docs/requirements/quality_and_open_questions.md`
  - 非功能需求與待補資訊。
- `docs/requirements/core/`
  - 放需求項目的細部延伸，不放總表型文件。

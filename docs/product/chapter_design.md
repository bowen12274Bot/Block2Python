# 章節設計

## 1. 章節結構原則

- 遊戲以節點式主地圖推進
- 主地圖視覺方向暫以類似 Candy Crush 的節點式關卡地圖作為參考
- 每個節點可觸發劇情、任務說明、示範關或支線練習關
- 主線負責推進故事
- 支線練習關負責累積能量並驗證玩家 Python 作答能力

## 2. 標準章節流程

1. 進入節點式主地圖
2. 觸發劇情 / 任務說明
3. 進入示範關
4. 解鎖新積木並建立積木與 Python 對應理解
5. 進入支線 5 題練習關
6. 累積電池能量並檢查是否超過 80%
7. 解鎖下一個主線節點

## 3. 關卡角色分工

### 示範關

- 目的：教學與新積木解鎖
- 表現：積木拖曳 + 驗證時顯示 Python 轉換結果

### 支線練習關

- 目的：練習 Python 作答
- 結構：固定 5 題
- 題庫：固定題庫
- 限制：預設只能以 Python 通關

### 工具包

- 目的：防卡住
- 用法：可在單題中不限次數開關
- 限制：只要曾開啟過工具包，該題能量固定為 10%

### 電池

- 起始值：0%
- 單題標準獎勵：20%
- 工具包題目獎勵：10%
- 通關門檻：整組 5 題後必須超過 80%（即 90% 或 100%）
- 失敗懲罰：整組練習關冷卻 3 分鐘

## 4. 章節規劃待補

- 第一章優先聚焦的積木與其對應 Python 語法
- 第一章城市主題
- 第一章示範關內容
- 第一章支線 5 題內容
- 各章對應的程式概念
- 章節難度曲線

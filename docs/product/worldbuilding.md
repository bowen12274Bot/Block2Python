# 世界觀設定

## 1. 作品名稱

- 暫定名稱：《Code Planet：拯救程式星球》

## 2. 世界背景

- 在遙遠宇宙中，有一顆名為 Code Planet（程式星球） 的星球
- 星球上的城市由「程式能量」維持運作
- 某日，反派 Bug King（錯誤王）破壞了系統，使各城市的程式開始失控
- 主角（玩家）與 AI 機器人 Byte 必須學習程式語言，修復各個城市的系統
- 每修復一個城市或系統，就能恢復程式星球的一部分能量

## 3. 主角與夥伴

- 玩家：待補具體身份、外觀與動機
- Byte：AI 機器人夥伴，負責陪伴、引導與提供輔助

## 4. 反派

- Bug King：破壞系統的主要反派
- 細部設定待補：
  - 動機
  - 能力
  - 與各城市異常狀態的關聯

## 5. 世界結構

- 各城市設定：待補
- 各城市對應的程式概念：待補
- 各城市的失控現象：待補
- 城市之間的推進順序：待補

## 6. 故事調性

- 科幻
- 冒險
- 闖關成長

## 7. 待補項目

- 玩家角色完整設定
- Byte 的個性與功能定位
- Bug King 的完整背景
- 城市數量與順序
- 各章節劇情主題

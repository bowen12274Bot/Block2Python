# UML

> 本資料夾用於放置 UML 圖（例如：Use Case、Sequence、Class、Activity 等）。

## 檔案與格式

- 主要維護格式：`*.md`（Mermaid）
  - 目的：可版本控制、可 review、容易跟文件互相連結
- 輸出圖檔：`*.png`
  - 目的：方便在文件與簡報中直接引用

目前內容：

- `docs/uml/system_architecture.md`：Mermaid 分層元件圖
- `docs/uml/system_architecture.png`：對應圖片版

## 命名規則（建議）

- `snake_case`（例如：`system_architecture.md`、`level_flow.md`）
- 若同一圖有多版本/多語系，建議用後綴：
  - `*_v0_1.md`
  - `*_zh_hant.md`

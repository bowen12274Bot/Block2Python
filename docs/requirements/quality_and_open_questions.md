# 品質需求與待補事項

- 文件版本：0.0
- 更新日期：2026-03-22
- 文件定位：補充需求文件

本文件整合非功能需求與待補資訊，用來承接功能需求之外的品質要求與未定案問題。

## 1. 非功能需求

- 目標平台為電腦單機。
- 畫面切換與編輯頁切換需保持基本流暢。
- 程式執行需維持隔離與可控。
- 冷卻與支線進度狀態需可正確保存與恢復。
- 玩家角色建立資料需可正確保存與恢復。

## 2. 待補資訊

- 各城市設定與章節主題。
- 玩家角色與主要衝突。
- 開場劇情腳本與進入頁前後的觸發時機。
- 控制浮頁上的劇情、Demo、練習關進入規則與優先順序。
- 劇情腳本的角色配置、旁白使用規則與實際演出節奏。
- 積木與 Python 的長期解鎖節奏。
- 美術風格與演出深度。
- 鏡頭與地圖推進形式。
- UI 承載方案。

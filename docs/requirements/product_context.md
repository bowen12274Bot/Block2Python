## 1. 劇情背景

- 作品暫定名稱：《Code Planet：拯救程式星球》
- 在遙遠宇宙中，有一顆名為 `Code Planet（程式星球）` 的星球。
- Code Planet 的城市由程式能量運作。
- Bug King 破壞系統後，城市程式開始失控。
- 玩家與 AI 機器人 Byte 透過學習程式語言修復各城市系統。
- 每修復一個城市或系統，就能恢復程式星球的一部分能量。
- `Bug King` 的真實背景與動機屬於後段劇情揭露內容，不應在故事起點一次說明完畢。

## 2. 本階段範圍

### 2.1 本階段包含

- 2D 遊戲畫面
- 節點式主地圖
- 劇情推進與對話框互動
- 進入頁與玩家角色建立
- 主線 / 支線關卡路線
- 程式編輯頁切換
- 積木與 Python 挑戰
- 工具包與積木解鎖
- 電池能量與支線練習關解鎖規則
- AI 助教
- 單機存檔

### 2.2 本階段不包含

- 多人模式
- 線上帳號與雲端同步
- 教師後台
- 最終版美術與完整劇情演出定稿

## 3. 系統流程

1. 玩家進入遊戲開場流程。
2. 在進入頁建立玩家角色，選擇男 / 女並輸入名稱。
3. 玩家角色建立成功後，先進入開場劇情流程。
4. 開場劇情完成後，進入節點式主地圖。
5. 在地圖上選擇目前可進入節點。
6. 關卡是主進程推進單位；劇情頁、關卡介紹頁與支線練習頁皆屬於關卡的一部分。
7. 進入該節點對應的控制浮頁。
8. 由控制浮頁選擇進入劇情、關卡介紹頁或支線練習關。
9.  完成當前練習頁內容後可返回主地圖。
10. 依序推進劇情、關卡介紹頁與支線練習關。
11. 符合電池條件後回寫結果並解鎖下一個主線或支線節點。

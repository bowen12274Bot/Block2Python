## 命名規則與延伸

- 主計畫：`<topic>_plan.md`
- 驗證文件：`<topic>_plan_verification.md`
- 評估或 review 文件：`<topic>_plan_review.md`
- 若需保留日期版本：`<topic>_plan_YYYY_MM_DD.md`

若要撰寫新的開發計畫，請先參考 `docs/contributing/ai_collaboration.md` 與相關 skill 指引，避免與既有計畫衝突。

# Godot 美術資產

這個資料夾用來存放 Godot 專案直接載入的畫面素材。

因為專案的大部分內容資產已經放在 repo 根層的其他資料夾，`godot_poc` 這邊只保留和畫面呈現直接相關的素材，所以不再額外包一層 `assets/`。

建議結構：

- `map/`
  - 主地圖背景、覆蓋圖層、關卡島嶼美術。
- `ui/`
  - HUD 紋理、面板、按鈕與圖示。
- `characters/`
  - 角色立繪與頭像。
- `vfx/`
  - 粒子、發光貼圖與特效素材。

凡是由 Godot 執行時直接讀取的畫面素材，統一放在 `godot_poc/art/...`。
